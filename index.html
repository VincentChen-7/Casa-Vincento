顾问总评（大数层面） 表面看松下比拉迷便宜约 6.8 万，但这是"假差距"，因为三家口径完全不同：① 拉迷施工是开口合同（"以实际发生量为准，多退少补"），松下是闭口包干（"零增项零漏项"）；② 拉迷定制柜按投影面积套餐制，松下按明细项目制；③ 拉迷不含瓷砖/洁具/开关/灯具，松下的拆除是第三方预估。真正要比，必须先把口径对齐（见第二节），再看单价和材料（见第四、五节）。结论预告：松下在"确定性"和板材/五金硬件上占优，拉迷在局改施工的专业度、瓦工工艺细节和售后条款上占优。最优解大概率不是二选一，而是"拉迷施工 + 用松下清单倒逼拉迷定制柜整改"，或"松下定制 + 第三方工长做局改"。

土建+铺贴覆盖了"缩小+隔出储藏室"的全部硬内容，工艺描述（地梁、闭水、1.8m上反）齐全。

松下做法（包干价内）

  • 客卫3.5㎡ 单独施工包干
  • 储藏室4.5㎡ 单独成项（含墙体裂缝处理、腻子、漆）
  • 定制清单：储物间松下SHEIF金属衣架1组 + 2P壁橱折叠门1樘
  • 新建工程清单含"马桶移位(1米内)""马桶移位管配件"专项

松下把"储藏室怎么用"直接给了解：金属衣架+折叠门，防潮、可拆卸、无板材甲醛焦虑。拉迷方案里储藏室只有一个空壳。

暗卫改造的生死线（两家都必须书面回答）
  1. 排风：卫生间C无窗，本应有排风道。若缩小后仍贴着原始风道，必须装大止逆阀+强力排气扇（建议松下/百朗，风量≥100m³/h）并入吊顶；若缩小后不再贴风道，则是硬伤，要设计方出处理方案。
  2. 马桶移位：改小后坐便大概率要移位。拉迷"下水改造"只写了台盆位！松下反而有"马桶移位1米内"专项。移位超过1m或用墙排/移位器都会显著增加堵塞风险——要求出点位图+移位距离。
  3. 地漏与坡度：暗卫无窗靠地漏排水，二次排水坡度、挡水坝（拉迷计了2道，好）必须做足。
  4. 防潮：储藏室贴着暗卫，整面共用墙必须防水做到顶+双面防潮处理，否则储藏室发霉是迟早的事。拉迷目前只报了卫生间内侧防水。必问
  5. 采光：公卫门建议选长虹玻璃/百叶门补光+透气。

阳台拆除专用坑位清单
  1. 先问物业：阳台拆改（尤其拆移门、动保温层）多数小区要报备审批，有的外墙统一管控，别签完合同才被物业叫停。
  2. 剪力墙红线：你给的第4张图（现场剪力墙图）显示阳台两端与客厅之间有配筋剪力墙（黑色）。拆阳台只允许拆门窗和栏板以下非承重部分，剪力墙一毫米不能碰。要求设计方在施工图上标注"可拆/禁拆"并盖确认章。
  3. 保温层与冷凝：阳台原外墙有保温层，并入客厅后该墙面要铲保温+挂网找平，否则冬天墙面结露发霉。拉迷阳台刷新20㎡按常规价算——必问是否含保温层拆除与防结露处理。
  4. 落差与地暖：阳台地面与客厅找平衔接，若客厅是地暖（备注"地暖空调物业指定厂家配合"），阳台区无地暖管，要处理分界与保温，防止两区温差导致地板接缝开裂。
  5. 移门拆除后：原推拉门下轨道/门槛要切割清理，拉迷已含，松下拆除要确认。

5.1 计价方式：套餐投影制 vs 明细项目制

维度拉迷松下
计价模型投影面积×1,666元/㎡ 套餐：20㎡=29,888 → 本单43.51㎡=72,488，套餐优惠后69,056；但全单柜子原价222,156，折后188,833；188,833+69,056-9,000=248,888 到手逐项明细：每个柜体列品名/品号/数量/面积，一口价176,550（含松下折门+SHEIF+房门+全部百隆五金+送货安装）
套餐结构解读43.51㎡投影里，套餐只覆盖基础柜体；222,156-72,488≈15万的部分都是"套餐外"（异形柜、开放柜、金属板、玻璃门、抽屉单元等）。这就是"29,888买20平"广告的典型变现路径。无套餐概念，所见明细即所付。

5.3 定制柜避坑要点（两家通用）

  1. 投影面积的"厚度陷阱"：投影计价下，柜深600mm和柜深350mm同价——薄柜（书柜、玄关柜）按投影算其实单价虚高。拉迷书房柜多为350~400mm薄柜（650宽系列），按投影算并不划算，要求薄柜部分按系数（0.6~0.7）折算。
  2. 见光板/包管板/收口条：定制三大隐形增项。拉迷清单里包柱展示柜算是把"包柱"明码了（好事），但其他柜体的见光板是否含要书面确认。
  3. 背板厚度：9mm vs 5mm背板成本差不少，问清拉迷背板规格（松下清单未列背板也要问）。
  4. 封边工艺：激光封边（PUR）>EVA热熔。问两家封边机和胶种，这决定甲醛释放和开胶概率。
  5. 五金明细表：要求两家各出一张《五金清单》：铰链/滑轨/拉手/拉篮/气压撑/翻门支撑的品牌型号数量。松下已基本做到（百隆+物美米上翻支撑），拉迷完全空白。
  6. 金属板浴室柜：拉迷"瓷泳黑金属板"要确认是整板金属（不锈钢/镀锌钢板烤漆）还是饰面工艺，前者耐用后者怕水。
  7. 安装与售后：松下含送货安装；拉迷定制含安装但售后条款在硬装单里（5年维护只针对施工表项目，柜体五金保修年限要单问，百隆五金正常质保是终身/10年）。
